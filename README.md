Hida's Garage — iTunes Music Explorer

Platform kurasi dan eksplorasi data rilisan musik global secara real-time yang memanfaatkan integrasi iTunes Search API.

## Fitur Utama
- **Live Data Fetching:** Mengambil dan menyajikan data katalog musik secara instan langsung dari server iTunes saat aplikasi dimuat.
- **Dynamic Search Filtering:** Memungkinkan pencarian lagu secara dinamis berdasarkan nama musisi atau judul album melalui form pencarian.
- **Interactive Audio Preview:** Dilengkapi dengan pemutar audio bawaan untuk memperdengarkan sampel lagu (preview track) berdurasi 30 detik.
- **Robust Error Handling:** Menggunakan arsitektur penanganan kesalahan (*try-catch*) untuk memastikan aplikasi tetap stabil dan menampilkan pesan informatif jika koneksi internet terputus atau server API down.
- **Premium Dark Interface:** Desain antarmuka adaptif yang minimalis, konsisten, dan elegan dengan kenyamanan mode gelap (*dark mode*).
